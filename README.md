# 拾页收藏 · iPhone 快捷指令

在 Safari 打开微信公众号文章 → 分享 →「拾页收藏」，把正文存成 Markdown 放进 Obsidian 的 `Clippings` 文件夹，再由「拾页同步」插件上传到拾页。

## 安装
用 iPhone **Safari** 打开（始终指向最新版）：

https://github.com/borischeng1984-hub/shiye-shortcut/releases/latest/download/ShiYe-Clip.shortcut

下载后到「文件 → 下载」点开，选「添加快捷指令」。

## 说明
- 只读取 Safari 里已经显示的页面，不重新请求微信；快捷指令里没有任何令牌或个人数据。
- 收藏完停在 Safari，不自动打开 Obsidian；下次打开 Obsidian 时同步插件自动上传。
- 同一篇重复收藏会提示「已经收藏过」，默认不保存。

本仓库只放快捷指令。Obsidian 插件在 shiye-obsidian-sync。
